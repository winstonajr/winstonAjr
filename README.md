## About

- Software Engineer at **SEMIT / Prefeitura de São Luís**, building and operating internal and citizen-facing systems:
  - **CIS API**: Java 21/25 (Spring Boot) and PostgreSQL with granular API Key access control and Blue/Green zero-downtime deployments via Docker and Nginx.
  - **Argus**: Lightweight availability and NOC monitor in Go, HTMX/SSE, and SQLite for autonomous VM, network (ICMP/TCP), TLS, and DNS diagnostics.
  - **Field Mobile Apps**: Flutter integrated with PHP 8.5 (Laravel 13) and PostgreSQL/PostGIS using timestamp-based delta synchronization.
- Previously Front-End Developer for 1 year at **QaCoders Academy**, building Next.js, TypeScript, and Tailwind CSS applications in agile squads.
- Studying **Systems Analysis and Development** at Faculdade Facint, with prior foundation in Interdisciplinary Science & Technology (ICT) at **UFMA**.
- Core interests: Clean Architecture, SOLID, offline-first sync protocols (LWW), asymmetric cryptography, and Linux-native workflows.

## Featured Projects

- **[Argus](https://github.com/winstonajr/argus)** — Lightweight NOC availability monitor in Go with cross-layer root-cause diagnosis, real-time SSE, SSL/TLS tracking, multi-channel alerts, SQLite, and Prometheus metrics.
- **Finlo** — Offline-first personal finance ecosystem combining a native Android app (Kotlin 2.x, Jetpack Compose, Material 3, Room with SQLCipher, BiometricPrompt) and a Go backend with bidirectional incremental sync and deterministic LWW conflict resolution.
- **[Koryvi](https://github.com/winstonajr/Koryvi) & [Koryvi License Manager](https://github.com/winstonajr/Koryvi-License-Manager)** — Desktop ERP and POS built with Electron, React 19, and SQLite, paired with an offline Go CLI using Ed25519 digital envelopes for tamper-proof licensing.
- **[DashDrop](https://github.com/winstonajr/dashdrop)** — Self-hosted LAN file-sharing service built with Go (Gin + sqlc), SQLite, and Vue 3.
- **Órbita (`tv_remote`)** — Flutter remote control for Android TV and TV Boxes implementing the Android TV Remote v2 protocol (ports 6467/6466) over local sockets without ADB.
