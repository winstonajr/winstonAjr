- 👨‍💻 Previously spent **1 year at QaCoders Academy** as a Front-End Developer, implementing **Clean Architecture & MVC** with **Next.js**, **TypeScript**, and **Tailwind CSS** in multidisciplinary agile squads (Product, QA, UX, Backend).

### ⚙️ Featured Engineering Projects

- **Finlo**: Personal finance ecosystem built under a strict **Offline-First** paradigm. Features a native Android app (**Kotlin 2.x, Jetpack Compose, Material 3, Room with SQLCipher encryption, BiometricPrompt, and custom Canvas charts**) and a high-performance **Go** backend with bidirectional incremental synchronization, monotonic version cursors, and deterministic **LWW (Last-Write-Wins)** conflict resolution.
- **Koryvi & Koryvi License Manager**: High-performance commercial Desktop ERP and Point of Sale (POS) system built with **Electron**, **React 19**, and **native SQLite**. Accompanied by a dedicated offline CLI/tool in **Go** implementing asymmetric cryptographic digital envelopes (**Ed25519**) for tamper-proof license generation.
- **DashDrop**: Self-hosted, high-speed local network (LAN) file-sharing service built with a **Go (Gin + sqlc)** backend and a reactive **Vue 3** interface with zero external cloud dependencies.
- **Órbita (tv_remote)**: Mobile remote control application for Android TV and TV Boxes developed in **Flutter**, natively implementing the **Android TV Remote v2** protocol (ports 6467 and 6466) via local low-latency sockets without requiring ADB or developer mode.
