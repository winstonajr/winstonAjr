## Featured Projects

- **[Argus](https://github.com/winstonajr/argus)** — Lightweight NOC availability monitor in Go with cross-layer root-cause diagnosis, real-time SSE, SSL/TLS tracking, multi-channel alerts, SQLite, and Prometheus metrics.
- **[Finlo](https://github.com/winstonajr/finlo)** — Offline-first personal finance ecosystem combining a native Android app (Kotlin 2.x, Jetpack Compose, Material 3, Room with SQLCipher, BiometricPrompt, Canvas charts, PDF/CSV export) and a Go backend with bidirectional incremental sync and deterministic LWW conflict resolution.
- **[Koryvi](https://github.com/winstonajr/Koryvi) & [Koryvi License Manager](https://github.com/winstonajr/Koryvi-License-Manager)** *(Private)* — Desktop ERP and POS built with Electron, React 19, TypeScript, Tailwind CSS 4, and SQLite, paired with an offline Go CLI/web tool using Ed25519 digital envelopes for tamper-proof licensing.
- **[DashDrop](https://github.com/winstonajr/dashdrop)** — Self-hosted LAN file-sharing service built with Go (Gin + sqlc), SQLite, and Vue 3.
- **[Órbita (`tv_remote`)](https://github.com/winstonajr/tv_remote)** — Flutter remote control for Android TV and TV Boxes implementing the Android TV Remote v2 protocol (ports 6467/6466) over local sockets without ADB.
- **[FinanTrack](https://github.com/winstonajr/finantrack-frontend)** ([Backend](https://github.com/winstonajr/finantrack-backend)) — Full-stack personal finance platform with Next.js, TypeScript, and Tailwind CSS frontend, and Node.js, Express, Prisma, PostgreSQL, and JWT backend containerized with Docker.
- **[react-simple-initials](https://github.com/winstonajr/react-simple-initials)** — Lightweight, customizable initials avatar generator for React & TypeScript projects.
